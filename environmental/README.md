# xiao-rp2040-cp / environmental

## Description
This folder contains a simple CircuitPython script designed to run on the XIAO RP2040.
The project includes an integration of the following Adafruit modules:
- 1.44" color TFT with microSD socket
- bh1750 light sensor
- sht40 temp humidity sensor

### Program overview
Temperature, humidity, and light levels are displayed in a Star Trek LCARS style.

### References
The base fonts I used were from the following site:
[Star Trek Fonts](https://github.com/wrstone/fonts-startrek/tree/master)

I used FontForge to convert the ttf file to bdf format using Adafruit's instructions here:
[Converting Fonts](https://learn.adafruit.com/custom-fonts-for-pyportal-circuitpython-display/conversion)
